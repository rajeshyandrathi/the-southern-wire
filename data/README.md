# data/images-used.json

Register of every photo used on the site. Keys are Wikimedia Commons file names
(as used in Special:FilePath URLs, unencoded) or local files in assets/covers/.
Values are the posts that use the photo.

Rule: a photo may be used by only one post. Before adding a photo to a post,
check this file; after adding, record it here. Posts listed against a photo that
has more than one post still need a unique replacement (backfill in progress).
